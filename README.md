# Workout Timer PWA

Version web installable, sans compte et sans backend.

Fonctions : AMRAP, FOR TIME, EMOM, INTERVAL, TABATA, préparation, pause/reprise, skip, vibration, bips/voix, sauvegarde locale, PWA et hors-ligne.

Mise en ligne : déposer tous les fichiers sur un hébergement HTTPS (GitHub Pages, Netlify, Cloudflare Pages, Vercel...). Puis ouvrir l'URL sur Android et choisir « Ajouter à l'écran d'accueil » ou utiliser le bouton d'installation.

Test local : `python -m http.server 8080` puis `http://localhost:8080`.
